## Account and Login Issues

GPTW Agent has two versions, and accounts are not shared between them:

China Mainland: [https://gptw.top](https://gptw.top) (supports WeChat and phone number login)

International: [https://gptw.top](https://gptw.top) (supports email, Google, and GitHub login; phone number sign-up was available before September 2024)

If you have used GPTW Agent before but cannot log in, try switching between the two versions.

## Basics

### Does GPTW Agent Cloud Support Bringing Your Own Model?

GPTW Agent Cloud currently does not support bringing your own model. You can only use the unified models provided by GPTW Agent.
